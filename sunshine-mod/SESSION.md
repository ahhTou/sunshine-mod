# 推流桌面设置

> 2026-10-28 · 指针与程序坞功能已部署，本机独立 MoonSession 已卸载；切换前已通过 macOS 权限、采集自检及真实桌面检查。

## 行为

在 Web 管理界面「配置 → 音频/视频 → Sunshine Mod · 本机桌面」配置：

- `macos_hide_cursor`：推流期间隐藏本机真实指针，默认 `disabled`。
- `macos_dock_position`：`0` 保持原位、`2` 底部、`3` 左侧、`4` 右侧，默认 `0`。

第一个连接开始时应用，最后一个连接结束时恢复；正常退出也恢复。程序坞原位置及对齐方式先写入配置目录的 `session-dock.plist`，保存失败则不移动，异常退出后下次启动重试恢复。指针隐藏只配平本进程成功持有的计数，不循环强制显示其他进程隐藏的指针。

隐藏真实指针与 SCK 的 `showsCursor = NO` 是两个独立行为。实现使用现有 macOS 私有接口，失效时保留推流；桌面模块独立于采集器，不通过电源断言猜测会话状态，不安装独立 LaunchAgent。
